# Mtaa KE

A modern Kenyan rental ecosystem connecting tenants, landlords, and property managers.

## Vision

To simplify renting in Kenya by creating a trusted digital platform for property discovery, communication, applications, and rental management.

## Core Features

Tenant:
- Search properties
- Apply for rentals
- Save favourites
- Communicate with landlords

Landlord:
- Manage listings
- Upload properties
- Track inquiries

Future:
- AI recommendations
- Rental price intelligence
- Digital agreements
- M-Pesa payments
